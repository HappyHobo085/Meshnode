# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's
**Security → Report a vulnerability** form on this repository (private vulnerability reporting).
Include the affected version (`meshd --version`), the platform, and steps to reproduce.

You should get an acknowledgement within a week. Fixes are released as a new version; there are
no backports to older versions.

## Supported versions

Only the latest release is supported. Meshnode is pre-1.0, and downgrades are not supported on
any platform (see `CONTRIBUTING.md`).
